# ProductUXProfile Specification

## Philosophy
**"Understand the product before designing the interface."**

Most software design failures occur not because of poor CSS or ugly buttons, but because the interface ignores the operational reality of the user's domain. In enterprise and industrial domains (like Advanced Planning & Scheduling, logistics routing, or trading consoles), treating the UI as a generic consumer SaaS dashboard results in catastrophic cognitive friction.

`ProductUXProfile` is the foundational schema generated by Alper Design OS's Domain Intelligence layer. It models the problem space before any line of UI code is authored.

---

## Schema Structure

```typescript
export interface ProductUXProfile {
  productName: string;
  productDomain: string;
  domainClassification: DomainClassification;
  personas: PersonaProfile[];
  primaryJobsAndTasks: JobToBeDone[];
  usageFrequency: UsageFrequency;
  informationDensity: InformationDensity;
  interactionStyle: InteractionStyle;
  criticalWorkflows: CriticalWorkflow[];
  requiredVisualPatterns: VisualPatternRequirement[];
  accessibilityConsiderations: AccessibilityRequirement;
  responsiveRequirements: ResponsiveRequirement;
  recommendedDesignDirection: DesignDirection;
}
```

### 1. Domain Classification
- `INDUSTRIAL_OPERATIONAL`: Manufacturing, factory scheduling, SCADA, teleoperation.
- `B2B_ENTERPRISE`: ERP, CRM, procurement, supply chain ledgers.
- `FINTECH`: High-frequency trading, risk analytics, banking operations.
- `DEVELOPER_TOOL`: IDEs, terminal workbench, observability consoles.
- `HEALTHCARE`: EHR, clinical patient timelines, medical imaging.
- `B2C_CONSUMER`: Content portals, social commerce, personal dashboards.

### 2. Information Density
| Level | Target Viewport | Row Height | Font Size | Primary Focus |
|---|---|---|---|---|
| `EXTREME` | 1440px+ | 20-24px | 11px | Sub-pixel data fitting, dense telemetries |
| `HIGH` | 1280px+ | 28-32px | 12px | Multi-track Gantt, ERP data tables, split panes |
| `MEDIUM` | 1024px+ | 40-48px | 14px | Standard SaaS, analytical cards |
| `SPACIOUS` | Responsive | 56px+ | 16px | Consumer web, touch-first mobile |

### 3. Interaction Style
- `KEYBOARD_FIRST`: Every action has an accessible hotkey (e.g. F2 inline edit, Alt+R re-sequence, Ctrl+Z undo).
- `HYBRID_MOUSE_KEYBOARD`: Drag-and-drop combined with keyboard accelerator shortcuts and right-click context menus.
- `TOUCH_OPTIMIZED`: 48px+ tap targets, swipe gestures.
- `GUIDED_WIZARD`: Linear step-by-step configuration sequences.

## APS Reference Fixture

In the manufacturing Advanced Planning and Scheduling (APS) domain:
- **Planner Persona**: Operates 8 hours/day continuously on high-resolution multi-monitor setups.
- **Critical Constraints**: Finite machine capacity, frozen horizons, dynamic re-scheduling, tool setup matrices.
- **Required Visual Patterns**: Split panes, synchronized Gantt timeline, dense data grid, bottleneck heatmaps, context menus.
