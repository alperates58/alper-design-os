# UI Blueprint DSL

## 1. Structure
The UI Blueprint DSL defines user interfaces as technology-independent data structures composed of Page Regions, Application Shells, and Component Blueprints.

## 2. Core Concepts
- `APP_SHELL`: Defines outer chrome, responsive sidebar, navigation items, breadcrumbs, user menu, and command area.
- `PAGE_HEADER`: Title, description, and primary page actions.
- `TOOLBAR` / `FILTER_BAR`: Search inputs, filter chips, saved views, and clear actions.
- `CONTENT_REGION` / `GRID_REGION`: Tabular records, metric grids, and master list content.
- `DETAIL_PANEL`: Slide-in drawers and split-pane inspectors.
- `ACTION_REGION`: Confirmation dialogs and bulk processing triggers.
