# Alper UI Recipes

## Purpose
UI recipes compose multiple canonical components and patterns into complete, production-ready screen layouts without hardcoding domain-specific business rules.

## Canonical Recipe Set
1. **`LOGIN_PAGE`:** Authentication screen with accessible form inputs, password reveal, error alert banners, and keyboard submission.
2. **`SETTINGS_PAGE`:** Categorized configuration panels with immediate switch toggles, form fields, and sticky footer action bar.
3. **`LIST_DETAIL_PAGE`:** Master-detail workflow with filter bar, responsive data table, and slide-in item inspector drawer.
4. **`DATA_MANAGEMENT_PAGE`:** High-density enterprise workspace with faceted filters, dense grid, row selection, and bulk confirmation barrier.
5. **`DASHBOARD_PAGE`:** Executive metrics overview organizing KPI stat cards, trend charts, and recent activity feeds without card soup.
6. **`FORM_PAGE`:** Structured single or multi-step input submission form with accessible field labels, inline error messages, and validation.

## Multi-Theme and Multi-Density Support
Every canonical recipe supports:
- Themes: `LIGHT`, `DARK`, `HIGH_CONTRAST`
- Densities: `COMPACT`, `COMFORTABLE`, `SPACIOUS`
