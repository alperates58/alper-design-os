# Alper Design Critic Skill

Expert design critique assessing software ergonomic quality and visual polish.

## Core Directives
1. **Separation of Aesthetics vs Correctness**: Clearly tag subjective visual observations with `isSubjective: true`. Never disguise aesthetic taste as WCAG 2.1 compliance.
2. **AI-Generated Smell Detection**: Flag decorative neon/purple gradients, generic floating cards with diffuse shadows, and inappropriate low-density layouts in industrial software.
3. **17-Dimension Audit**:
   - Visual hierarchy & typography scale
   - Spacing rhythm & alignment
   - Operational data density
   - Empty, loading, and error states
   - Micro-interaction feedback & hotkeys
   - Desktop keyboard efficiency vs mobile ergonomics
