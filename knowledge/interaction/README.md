# Knowledge Architecture: Ergonomics & Interaction Models

Guidelines for desktop, keyboard-first, and high-frequency operator interaction styles.

## Interaction Paradigms

1. **Keyboard-First Ergonomics**:
   - Universal hotkeys: `Ctrl+Z` (Undo), `Ctrl+Y` (Redo), `F2` (Inline Edit), `Alt+R` (Re-sequence/Replan), `Space` (Quick Inspect), `Escape` (Dismiss).
   - In data tables and timeline grids, all cells and allocation blocks must be focusable and operable via standard directional arrow keys.

2. **Hybrid Mouse & Drag Operations**:
   - Snap-to-grid guidelines during timeline dragging.
   - Real-time ghost placeholder showing prospective drop position before commit.

3. **Multi-Pane Splitter Behavior**:
   - Double-click on splitter divider resets pane to default golden ratio.
   - Collapsed panes expand on hover or shortcut without jarring screen layout jumps.
