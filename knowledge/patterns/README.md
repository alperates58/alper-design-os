# Knowledge Architecture: UX & Visual Patterns

High-density, technology-independent UX patterns mapped by Alper Design OS.

## Core Patterns

1. **Multi-Track Timeline & Activity Allocation**:
   - Continuous horizontal time axis with synchronized zooming, panning, and resource tracks.
   - Used for machine allocation, project scheduling, event sequencers.
2. **High-Density Virtualized DataGrid**:
   - Sub-32px row heights, fixed sticky headers, multi-column sort, inline cell editing, and pinned columns.
   - Operable with 50,000+ records via virtual windowing.
3. **Multi-Pane Workbench with Resizable Splitters**:
   - Primary view + Backlog drawer + Inspector side pane.
   - Persistent user layout state.
4. **Capacity Utilization & Threshold Alert Heatmap**:
   - Real-time percentage indicators and bottleneck violation warning pills.
5. **Contextual Action Palette & Radial Menus**:
   - Fast right-click or `Shift+F10` in-place actions.
